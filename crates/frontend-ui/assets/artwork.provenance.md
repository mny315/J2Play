# Launcher and startup artwork

These project assets are distributed under the root [MIT License](../../../LICENSE).
The launcher icon was supplied by the project owner as original project artwork.
The startup emblem was generated with OpenAI's image-generation service on
2026-09-07 at the owner's direction. This records the existing attribution in
`NOTICE`; the original generation prompt is not retained in this repository.

The launcher PNGs are density variants of the project icon; Android XML
resources compose its adaptive icon and splash presentation. Linux uses the
192 × 192 `mipmap-xxxhdpi` icon. The startup emblem belongs to the shared UI.
These assets contain no supplied game or phone firmware artwork.
